Tahap 11 - Latihan Mandiri dan Pengumpulan

1. cache segar adalah data lokal yang masih baru dibawah batas waktu tertentu (TTL).
2. cache basi adalah data lama yang tetap ditampilkan sebagai cadangan ketika perangkat offline.
3. first run offline adalah kondisi saat perangkat kehilangan koneksi internet tanpa adanya data atau salinan sama sekari di memori lokal.
4. label sstatus data penting karena agar si pengguna mendapat info yang transparan dan A1 mengenai kebaruan informasi cuaca yang sedang mereka lihat.
